COMO GERAR O APK DO TELAPLAY (sem instalar nada no computador)

1. No GitHub, abra o seu repositorio PRIVADO (ele guarda a chave debug.keystore).
2. Envie para o repositorio (Add file > Upload files) o conteudo desta pasta:
   www, android-res, capacitor.config.json, package.json e debug.keystore.
   Arquivos com o mesmo nome substituem os antigos.
3. A pasta oculta .github nao sobe ao arrastar. Abra .github/workflows/build-apk.yml no
   repositorio (ou crie com Add file > Create new file), clique no lapis e troque TODO o
   conteudo pelo do arquivo build-apk.yml desta pasta. Clique em Commit changes.
4. Abra a aba Actions e espere o V verde (5 a 10 minutos). Se nao iniciar, clique em
   "Gerar APK" > Run workflow.
5. Na execucao concluida, role ate Artifacts e baixe "telaplay-apk". Descompacte: o APK e o app-debug.apk.
6. Instale no celular (autorize "fontes desconhecidas" se pedir).

PARA ATUALIZAR SO O APP (sem mudar nada no Android): troque apenas www/index.html.
PARA RECEBER MUDANCAS DO ANDROID (tela cheia, rotacao, icone): troque tambem o build-apk.yml.
Para conferir: na execucao do Actions deve existir o passo "Tela cheia, rotacao e tela de abertura (TelaPlay)".
Instalando por cima do app antigo: se o Android recusar ("app nao instalado"), desinstale o antigo uma vez.
